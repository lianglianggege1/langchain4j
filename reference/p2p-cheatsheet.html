P2P 模式速查表

数据驱动激活 · 稳定态终止 · 变脏重跑。配套课程：第 2 课

一句话定位

P2PPlanner 不做智能决策，只做机械激活：输入齐 → 执行；输入变 → 重跑；全员静止 → 结束。agent 间零调用，全靠 AgenticScope（STAR 拓扑）传数据。

构建模板

// 1. 声明 peer：@V = 输入(前置条件)，outputKey = 输出(效果)
LiteratureAgent a = AgenticServices.agentBuilder(LiteratureAgent.class)
        .chatModel(model).tools(tools).outputKey("researchFindings").build();

// 2. 装配：typed 入口（参数直接成为状态）
ResearchAgent r = AgenticServices.plannerBuilder(ResearchAgent.class)
        .subAgents(a, b, c).outputKey("hypothesis")
        .planner(() -> new P2PPlanner(maxInvocations, exitCondition)).build();
r.research("black holes");

// 2'. 装配：untyped 入口（自然语言 → LLM 提取变量，必须给 ChatModel）
P2PAgent r = AgenticServices.plannerBuilder(P2PAgent.class)
        .subAgents(a, b, c).outputKey("hypothesis")
        .planner(() -> new P2PPlanner(model, maxInvocations, exitCond)).build();
r.invoke("produce a research about black holes");

AgentActivator：两个标志位

标志语义置位 / 复位
executing（锁位）当前在执行，防重复调度、防误判稳定态startExecution 置 / finishExecution 复
shouldExecute（脏位，初始 true）数据要求（重新）执行激活时清 / 我的输入 key 被改时置回

canActivate = !executing && shouldExecute && 全部输入 ∈ scope（P2PPlanner.java:145-147）

决策三方法

方法时机职责
firstAction循环开始一次scope 有 p2pRequest → VariablesExtractorAgent(LLM) 提取变量写入 scope
nextCallAction每轮扫描收集 canActivate 者 → startExecution + counter+=n → call(agents)；n=0 且无人执行 → done()（稳定态）
nextAction每次完成回调terminated()? → done()；否则 finishExecution(刚完成者) + 全员 onStateChanged(outputKey)（变脏广播）

运行时关键点（PlannerLoop）

  • 分发三分支：0 个 agent → Thread.yield() 等待；1 个 → 同步；多个 → CompletableFuture.allOf 并行
  • 完成回调 onSubagentInvoked 在 ReentrantLock 内：composeActions(当前动作, nextAction) 合并，空 call 可丢弃，done 优先
  • 每次回调把 executionState()（invocationCounter）存入 scope，崩溃可恢复
  • 结束时 result() 读根 agent 的 outputKey 返回

终止三保险

保险条件适用
稳定态 quiescence无人可激活 ∧ 无人执行中无环 DAG（必然沉降）
硬闸counter ≥ maxAgentsInvocations（缺省 10）有环必配
软闸exitCondition(scope, counter)业务质量目标（如 score ≥ 0.85）

两个坑（P2PResearcherIT 至今 @Disabled）

  • 环依赖振荡：agent 的 outputKey 是（自己或他人的）输入 → 每轮写回都触发再激活。设计时先画依赖图，见回边必配双闸。
  • 空动作自旋冻结：done 被空 call 覆盖 → 主循环永久 yield。回归测试 P2PPlannerComposeActionsIT。

测试锚点速查

测试钉死的规则
P2PPlannerTest · shouldNotInvokeMore…ping-pong 互喂，精确执行 max 次（硬闸）
P2PPlannerTest · shouldStopBefore…ExitCondition软闸优先于硬闸生效
P2PPlannerTest · should_terminate_when_no_agent…无环 DAG 沉降到稳定态
P2PPlannerTest · should_not_terminate_while…executing在途 agent 存在时禁止判稳定态（假稳定）
P2PPlannerComposeActionsIT · p2p_should_not_freeze…composeActions 不丢 done（防冻结）
